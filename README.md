# Puckbound

3-on-3 arcade hockey RPG for phones and browsers. You run the Snowcrest Foxes (rename them in the club editor) through the Frostline league. Plain HTML5 canvas and ES modules, with no build step and no dependencies.

## Run it

```bash
cd glacial-strikers
python3 tools/serve.py 8080
```

Open http://localhost:8080 on this computer. To play on a phone on the same Wi‑Fi, open `http://<this-computer's-IP>:8080` (on a Mac, `ipconfig getifaddr en0` prints the IP). If macOS asks whether Python may accept incoming connections, allow it.

The game needs to be served over http; opening `index.html` straight from disk won't load the modules.

### Offline

- **Single file:** `node tools/build_offline.mjs` writes `dist/puckbound-offline.html`, one file of about 55 MB with everything embedded. Double-click it on any computer to play with no server or internet. It isn't kept in git: the Pages workflow (`.github/workflows/pages.yml`) builds it on every push to main and publishes it with the site, at `dist/puckbound-offline.html`.
- **Install on a phone (home screen, offline):** the game is a Progressive Web App with a manifest, icons and a service worker that caches every file the game uses. Phones only allow this from an **https** address. Host the folder on any https static host (GitHub Pages, Netlify, Cloudflare Pages), open it on the phone, then:
  - Android (Chrome): menu, then *Install app*. The title screen also shows an Install button.
  - iPhone (Safari): Share, then *Add to Home Screen*.
  After the first visit it launches fullscreen in landscape and plays with no connection. Progress is saved on the phone.
- After changing any game file, run `node tools/build_pwa.mjs` so the service worker picks up the new version. Pushing to main deploys: the workflow publishes the repository to GitHub Pages with the offline file built fresh.

## Controls

| Action | Keyboard | Gamepad | Touch |
| --- | --- | --- | --- |
| Skate | WASD / arrows | Left stick | Drag on the left half |
| Sprint | Shift | RB / LT | SPRINT |
| Shoot (tap = wrist, hold = slapshot) / Check | J or Space | X / RT | SHOOT / CHECK |
| Pass / Switch player | K or Enter | A | PASS / SWITCH |
| Signature skill | U or Q | B / LB | Skill button |
| Ultimate | I or E | Y | Star button |
| Pause | Esc / P | Start | Pause icon |

**Pull the goalie:** H on keyboard, Back/View (Create on PlayStation) on a gamepad, or the PULL GOALIE touch button. It's available when you're behind and the other team needs one more goal.

Hold shoot while a pass is on its way to fire a **one-timer**. Your skates plant while you hold it, so steering only aims.

**Local versus (2 players):** P1 uses WASD, F shoot/check, G pass/switch, Left Shift sprint, R skill, T ultimate. P2 uses the arrows, K shoot/check, L pass/switch, Right Shift sprint, O skill, P ultimate. With two gamepads each player gets one; with one gamepad it goes to P2. Esc pauses.

**Gamepad in menus:** the D-pad or left stick moves a highlight, ✕/A selects, ○/B goes back or closes a pop-up, L1/R1 switch hub tabs, and the right stick scrolls. PlayStation and Xbox pads both work (Chrome needs a button press before it sees the pad).

**Shootout goalie (and penalty shots against you):** on the rival's shot you're in goal (one chance each: a save or a poke check ends it), with goal mode's controls: the stick nudges the angle (with Settings › Aim assist's help tracking the shot), shoot = butterfly, pass = dive, skill = poke check.

**Goalie mode** (Play as: Goalie): steer to move Halla, shoot (J / X / BLOCK) drops into the butterfly, pass (K / A / DIVE) dives toward the stick, skill (U / B) pokes, sprint gives quicker feet, ultimate (I / Y / star) fires Wall of Ice. Holding the puck, shoot passes toward the stick and pass rims it around the boards (CLEAR).

## What's in this build

- **Match:** first to 5, 3 skaters + AI goalie per side, possession, passing with lead (a dashed gold ring at a teammate's feet shows who a pass would go to right now), wrist/slap/one-timer shots, smart aim with manual corner aim, checks with hit-stop, stick-checks, shot blocks, rebounds, posts, goalie dives and freezes, faceoffs.
- **Characters:** Nix (Glacier Glide trail / Absolute Zero), Volta (Bolt Dash / Thunderclap with a telegraphed wind-up), Bram (Bedrock / Monolith wall).
- **Power pucks:** fire, ice, lightning, gravity. Orbs spawn in contested spots and the power belongs to the puck.
- **Arena twists:** speed lanes (semifinal), cracked ice (final).
- **RPG:** EXP and levels, stat points, perk choices at levels 3/5/7, gear with tradeoffs, training, a 5-stage tournament with dialogue, seasons and exhibitions. Progress saves in the browser.
- **First steps:** Coach Brekka introduces the hub one thing at a time (play a match, skill points, training, the shop, scouting, the daily challenge, your club's name and colours, trophies), pointing at the station or button with a speech bubble. That's one new tip per visit, each shown once, and "No more tips" turns them off. Matches add one-time hints the first time an ultimate or chemistry combo is ready. Saves with three or more matches skip the tips.
- **Feel:** reactive pixel crowd, flickering arena lamps, goal lamp, slow-mo goals, confetti, ice scratches that build up, snow, screen shake.
- **Phones:** only the art the current scene uses stays decoded (about 40 MB on the title screen and 60–90 MB in a match, down from 200 MB); the rest sits in the browser cache. Rival team colours are recoloured with a per-colour cache (about 45 ms instead of half a second), the near-bench fans are cached as small sprites, and if a match runs below about 45 fps the game lowers its render resolution step by step. Scene art has its own pages too: the title art, the hub characters and the arena-rule sprites are decoded only in the scenes that use them.
- **Soundtrack:** 16 SNES-style chiptune tracks played live by the game's own tracker engine (no audio files): the title theme, the locker room, a match theme for each arena (Frostline Faceoff, Ember Dome, Aurora Palace, the Pine Pond jig, the Golden Hall's stomping march with horn calls and timpani, the Dark Aerie's gothic arpeggios over trap hi-hats), the Winter Classic anthem (brass, flute and sleigh bells), the Cup Final, shootout, practice, awards night, story scenes, and victory and defeat. They share the Puckbound motif. When either side is a goal from winning, extra harmony and drum layers fade in. Jingles mark goals for and against, wins, losses, level-ups, signings, achievements, the daily challenge, award envelopes and the championship. Settings has music and sound volumes and a Music room to play any track.
- **Sound:** each arena has its own acoustics (a big echo in the Ember Dome and Aurora Palace, almost none outdoors on Pine Pond) and its own goal horn: Frostline's two-blast horn, a volcanic horn and flame burst, a royal fanfare with chimes, cowbells with a hand-cranked siren, a ram's horn over a gong in the Golden Hall, and a low bell with cawing ravens in the Dark Aerie. The visitors' goals get a siren instead. Sounds are panned to where they happen. The crowd murmurs and shouts, cheers its own team, groans or boos at the visitors, and chants. Glove catches, pad saves, poke checks, posts, glass rattles, nets and the shop register all have their own sounds, and every speaker in a dialogue has their own voice blip. Audio runs at 32 kHz (the SNES's own rate). Drums, most effects and the crowd's "ooh" are synthesized once into samples when the audio starts, then played back, so a full match costs about 6% of one core on a recent laptop. Settings › Audio quality has a Light mode for slower phones (Auto picks it on low-memory devices): 24 kHz, no backing layers and fewer crowd voices.
- **Chemistry combos:** each pair (Nix+Volta, Nix+Bram, Volta+Bram) levels up chemistry from passes, assists and combo goals. From level 1, a pass between the pair followed by a quick shot fires their combo: Frostbolt, Avalanche or Thunderquake. Consecutive passes build a pass chain that adds shot power. Rivals have chemistry too.
- **Supers and archetypes:** every player mixes an archetype (how they play) with a super (an element's skill and ultimate). The archetypes are Playmaker, Speedster, Blueliner, Sniper, Dangler, Grinder and Enforcer: each has a trait that's always on (faster passes, faster sprints, harder slapshots, better aim, checks that slide off a puck carrier, more stamina and steals, harder hits) and the middle perk choice. The elements are Frost, Thunder and Stone (our cast's) and three newer ones: **Ember** (Heat Check ignites your next shot; Firestorm is a blazing shot that knocks back anyone it passes and can't be held), **Gale** (Tailwind boosts you and teammates nearby; Cyclone is a whirlwind that blows opponents out and pulls a loose puck to you) and **Shadow** (Fade makes checks miss and your passes impossible to pick off; Eclipse hides the puck so the goalie reads it late). Combos come from the two players' elements: the cast's three, plus twelve more for the newer pairs, each mixing its elements' parts. The Comets', Lynx's and Ravens' wingers play Ember, Gale and Shadow; rivals' players have archetypes that fit them, and signings and drafted rookies bring theirs. Every player shoots left or right (shown on the cards; the sprites follow once the art is drawn both ways). `tools/test_supers.mjs` checks every new skill, ultimate, trait and combo and plays matches with them.
- **Legends:** now and then, after a match, a legend turns up in Team › Scouting for three matches: Fáfnir, a dragon of a defender with a shot like dragonfire (Ember), or Fenrir, a wolf of a sniper (Shadow). They're twins: once one is yours, the other comes looking sooner, and dressed together they have a bond from day one, faster passes to each other and their own combo, **Ragnarök**. Their own art is in for all of it: portraits, the reveal painting, skating in all eight directions (drawn left-shot; Fenrir is mirrored to shoot right), banners, and a shared celebration after a Ragnarök goal (`?legends=1` makes one visit now). **Test run:** open the game with `?twins=1` to play with Fáfnir on defence and Fenrir on the wing: it plays on a copy of your save, nothing is written and nothing goes online, and a badge says so.
- **Training camp:** Change… on any Team card: a new super from Ottar's element stones (220 coins) or a new style from Brekka's camp (180 coins), each once a season per player. Perks carry over as the same choice on the new list. Team › How supers work explains styles, supers and which pairs make which combo; Coach Brekka's tips point at both.
- **Trades:** in Team › Scouting, Trade next to a rival player who'll take your call: send one of your signings or drafted rookies (not the cast or the legends) plus coins when they're worth less than the price. What you send is worth its price (or a rookie's promise) and more for every level since, and each rival counts the styles it likes a quarter more (the Rams like Enforcers and Grinders, the Comets Snipers and Blueliners, and so on). Whoever you send joins that club's reserves, and their old club plays a newcomer in the slot.
- **Stick hands on the ice:** a sprite set can say which hand each facing is drawn with; a player who shoots with the other hand is drawn as the opposite facing, mirrored, where that facing is drawn with the same hand (sets drawn left-shot in all eight directions, like the twins' and the parts body; the cast and the newcomers have native west views from Batch AK, with each facing's hand recorded). One-timers taken on the forehand (a pass from the shooter's stick side) fly 6% faster and truer, backhand ones 4% slower.
- **Goalies for hire:** beat a rival and their goalie will take your call too (Team › Scouting). Every goalie has a **goaltending style**: Halla is a Hybrid, and the rivals' are a Scrambler (quick across, a little less reach), a Butterfly (seals the ice, opens up high), a Wall (covers more net, slower, stays home), a Puck-handler (out to play pucks behind the net) and a Reader (reacts sooner, slow across for a pass). A signing joins a level below Halla in our colours; choose who starts in Team (the starter takes the saves' EXP and is the one you play in goal mode), and give each their own pads. Their old club plays a backup. Career numbers and the Iron Wall follow whoever was in net. `tools/test_goalies.mjs` checks the styles, signing and the backup, and plays AI matches with each style (all within about 2% save percentage of each other).
- **A living league:** the rivals fill the gaps your signings leave. On Draft Day the two prospects you pass on go first to clubs with a hole in that position, and they grow each season after their first; between Draft Days a club with a gap now and then signs a free agent (in the league news after a match). A rival whose players will take your call may ring after a match with a trade offer of their own: they ask for one of yours (a style they like first), offer whoever of theirs is closest in value, and coins even it out either way (when yours is worth more, they pay half the difference). `tools/test_moves.mjs` checks it.
- **Stick handling and the deke:** the puck rides on the blade, dangled forehand to backhand when there's time; a stick reaching in on the forehand side gets it pulled across to the backhand (shielded: commentary, an achievement, a daily goal). A carrier gliding or under 200 is drawn working the puck in their own stick-handling poses, and skaters cross over through hard turns at speed (Batches BD/BE: our cast, the parts bodies and the newcomers). The drawn puck sits on the painted blade: measured points for those poses, and for the ordinary skating frames points the builder reads off each gear mask's stick (`tools/blade_points.py`). A quick tap of sprint with a defender in your face dekes: a cut away with the puck pulled in and hard to poke, and near the goalie it can make them bite the wrong way (Sold It, an achievement, for scoring off the bite). The AI dekes too, and the Breakaway drill teaches it.
- **Tip-ins:** a teammate's shot going by a stick in the slot is now and then tipped (a quarter of the time for an AI stick, more for a better shooter; a player in front pressing SHOOT as it goes by tips it 70% of the time), off at 8 to 24 degrees from its line, so the goalie, set for the shot, has to read it again late: the tipper's goal, the shooter's assist. When the player has the puck out at the point, the winger goes to the front of the net for it (the AI's own point men pass instead, so AI matches play as before). About one point shot in ten gets tipped and about one tip in five goes in. **Screens:** a skater (either side) standing in a shot's way between 40 and 150 out in front of the goalie makes their read 0.05 s later (about one shot in sixteen), and the commentary notices a goal through traffic. With the player in goal, a screened puck is drawn faint until it's past the body in the way.
- **Faceoffs:** press when the puck touches the ice. Going while it's still in the air holds you back until the other centre has had their chance, so mashing loses the draw; a press right on the drop wins it clean (Off the Drop, three in a match). A puck nobody can reach for six seconds (wedged behind a net, pinned on the boards) is whistled dead and faced off at the nearest painted dot, and penalties face off at a painted dot too.
- **Free agents:** after a few matches Vigga, the agent, has a list in Team › Scouting: a skater for each position and now and then a goalie, made from parts with a style, a super and a stick hand of their own, and new faces every five matches. They're veterans: they join at your line-up's level with the perks for the levels they've had, don't grow faster than anyone else, and cost what they're worth (a goalie is made from parts too: a mask of their own, one of six designs in a paint colour, on a standard, big or small build). Vigga stands by the lockers while she has a list. `tools/test_agents.mjs` checks the market.
- **Poaching matters:** a rival's reserve is a step down from the star you signed (their two best stats a point lower), and simulated games feel every slot you emptied and a backup in goal; a draft pick that grows or a signing closes some of the gap. Rivals' draft picks and signings are made from parts too, in their team's colours.
- **The league grows:** from a save's second season two expansion clubs join, the **Glacier Owls** (patient, sharp-eyed) and the **Thunder Moose** (big and loud), and Kip announces them: eight teams, seven rounds, still a top-4 playoff. Their players are made from parts in their colours and can be scouted and signed like any rival's; their goalies are made from parts with masks of their own (the Owls' stars, the Moose's wolf teeth). Each club has its own building (the Observatory, the Longhouse), crest, mascot, scoreboard, arena banner and a captain's cut-in. A season already under way keeps its six teams. `tools/test_league.mjs` checks the schedules, a full expanded season and the new clubs.
- **The league gets better:** each season after the first, every rival player gains a point on their four best stats (four seasons at most) and rival goalies a point a season (three at most); and after a season you won most of, a league you've run away from catches up some (rivals up to three more points on their best stats, goalies up to three on reflexes and positioning, sized to how far ahead your line and your goalie are), with a line in the league news. In simulated saves that keeps later seasons near 70% wins instead of over 90%; a rival star costs 12% more each season and joins with what they've grown; free agents grow too, with stars more common later. The top levels take longer (a season or so each past level six). `node tools/sim_seasons.mjs [seasons] [seeds]` plays a save through several seasons headless (real AI matches, a player who trains, spends points, buys gear and signs upgrades) and prints a line per season: record, coins earned and spent, levels, signings, and our line's stat total against the league's.
- **Rival careers:** every rival star has an age and gets a year older each season: the young improve, those past thirty decline, and at 34 they retire after the awards, their place going to a Draft Day pick or a signing. Scouting shows their ages (and when it's their last season). Your own players don't age; they grow by levels. `tools/test_careers.mjs` checks the careers and the news.
- **Around the Frostline:** the League tab keeps the league's news, newest first: every signing (yours and the rivals'), draft pick, trade, retirement and champion.
- **Coach tips** for the newer systems: the free-agent market, rivals' goalies, trades, goalie camp and the expansion clubs, one at a time as each becomes useful.
- **Goalie camp:** any goalie can change their goaltending style once a season (200 coins) from the Team tab.
- **The legends' moments:** when a legend turns up, Kip announces them over the reveal painting; the second twin comes looking for the first; and before the twins' first game side by side, Kip makes the most of it.
- **Auto-quality:** during matches the game watches the frame rate; on a slow device it steps down the resolution, then the effects, the crowd and the snow (`src/quality.js`), and steps back up when there's room. Each device remembers where it settled. `tools/test_quality.mjs` checks the ladder.
- **Draft Day's hall (Batch AD):** Kip at the podium behind the prospects, card rims by potential (bronze, silver, gold), and the rookie pulling on our jersey after the pick.
- **The linesman (Batch AG):** only for the look: he holds the puck at the dot and drops it (the game's puck stays hidden while it's in his hand), skates clear to the far boards and follows play, ducks a puck that comes his way, and makes the calls: each penalty's own signal (interference, charging, boarding; Batch AS; hooking and the penalty shot, Batch BL), an arm up for a delayed penalty, a point at the net for a goal and a wave-off for one that doesn't count (`src/linesman.js`). `tools/test_part2.mjs` checks him and every Part 2 mapping.
- **Players from parts (Batch AJ):** a body drawn without a head, a head placed on each body frame's anchor (mirrored where the anchor says), and skin and hair recoloured through the head's mask, so a player's look is a small recipe (body, head, skin tone, hair colour; `src/modular.js`): three builds (defenders lean big, forwards slim), ten heads, six skin tones and eight hair colours. Drafted rookies get a look of their own (older rookies too), drawn in matches and composited into portraits on their build's shoulders, and pull on our jersey with their own face on Draft Day (the standard build; Batch AP brings the other two). `tools/test_draft.mjs` checks the looks, the recolouring and the head placement.
- **Penalty shots:** a skater hauled down from behind on a breakaway (nobody else back) gets one about half the time: no power play, the fouled skater goes alone from centre ice while everyone else waits on the benches; one chance, a save ends it (From the Spot, for scoring one). When it's against the player's team, the player takes over in goal for it. About one every four matches.
- **Hat tricks:** a skater's third goal of a match brings the hats down from both stands (simple pixel caps until their art, Batch BM, is in), a roar from the crowd, and they lie on the ice until the next faceoff.
- **Name your rookies:** a drafted rookie or a signed free agent can be renamed from their Team card (or right after the pick on Draft Day); the cast, signed stars and legends keep their names.
- **After a match:** after a loss Coach Brekka names one thing to work on, from the numbers (penalties taken, a hot goalie, being outshot, the faceoffs, the puck); the three stars of the game, from either team (goals count most; a goalie with a big night can be one), and a shot map: every shot on goal where it was taken from, goals ringed in gold. After an exhibition Play again starts the same match straight away. The first hub visit after an update shows a What's new card from the coach (`src/whatsnew.js`), once.
- **Penalties and power plays:** hitting a skater away from the puck can draw interference, very hard hits can draw charging or boarding, and reaching round a faster carrier from behind can draw hooking (half as often for the player's own skater, whose stick is out on its own: a player who only chases draws about one in four matches). Calls are delayed: the linesman's arm goes up (DELAYED PENALTY on the HUD) and play goes on while the fouled team has the puck, the whistle coming when the offending team touches it, and a goal by the fouled team in the meantime wipes the minor out. The fouled team can pull its goalie for an extra attacker while it waits (it costs nothing: the other side can't touch the puck without the whistle); the AI does. The player sits 15 seconds in a glass penalty box built into the far boards (the door swings, a red light blinks and the timer hangs above it; on Pine Pond it's a log box set into the snowbank with a lantern, Batch F), the faceoff moves to a painted dot on the offender's side of centre, and a power-play goal ends it early. Power-play goals and penalty kills pay bonus coins.
- **Pull the goalie:** trailing when the other team needs one more goal, swap Halla for an extra attacker. She skates off to the bench, and if you send her back mid-play she skates back to the crease, so the net is open for about a second. The AI pulls its goalie too, so watch for empty nets.
- **League and playoffs:** a 6-team round robin (5 rounds). Your games are real and the rest are simulated, with a standings table and the top 4 into semifinals and a Cup Final. Seasons repeat with tougher rivals. **Season goals:** each season Coach Brekka sets three (one for the table, like making the playoffs or the final; one for your play, like 15 goals, a 5–0 or three wins in a row; one for a big night, like the Winter Classic, the All-Star Game, a drafted rookie's goal or beating last season's champions), shown under the standings and on the game-plan screen, each paying 100 to 220 coins the moment it's met and 150 more for all three, with a recap at the end of Awards Night (`src/goals.js`, `tools/test_goals.mjs`). Trophies › Seasons keeps every season since: the finish, record, goals for and against, how the playoffs went and the season goals met.
- **Goalie mode:** play a whole match as Halla while the AI skates your line. Choose Play as: Goalie in quick play or on the game-plan screen before a league match (it's remembered; daily challenges stay skaters only). Halla holds the angle and the stick nudges her in, out and across; Settings › Aim assist sets how much she helps track a shot (a moment late and not exactly, like the AI goalie reads it), and off means you place her yourself. The butterfly covers the ice but slows her slide and leaves the top open, the dive throws her across, the poke check knocks the puck off a carrier in close, and a caught puck waits for you to pass toward the stick or rim it. Saves charge her ultimate, Wall of Ice: five seconds of extra reach and quicker feet, as a wall of ice crystals rises across the crease, shimmers, and shatters when it ends (Batch Q art). The camera keeps her in the picture while the puck is in her end, she earns double EXP, and a win unlocks Between the Pipes. `tools/test_goalie.mjs` checks the controls and plays bot matches: a bot holding the angle with timed butterflies saves about 90% and wins about 70% of its matches. Every goalie covers a disc that's the same at every angle (a sharp-angle shot no longer slips past a goalie it hits square): the AI's at 0.7 of their reach, the player's (goal mode, shootouts, penalty shots) at goal mode's own reach, `HUMAN_REACH`.
- **All-Star Game:** once a season, after league round 2, at home. The fans vote in the league's stars from this season's numbers: your top scorer leads your bench with the top star of each of the two rival teams with the biggest names, in your colours, and those two teams' next three wear the League All-Stars' navy and gold, with the better of their goalies. All-Star rules: no penalties and ultimates charge twice as fast. Kip Vance calls it, it doesn't count in the standings, only your own players earn EXP, and a win pays a 260-coin purse, unlocks an achievement and goes in the trophy case. Two rival teams at most, so a phone holds the art (about 130 MB of decoded art in the game, against 98 MB for a normal match). Before the game comes **Skills Night**: your All-Star against the other five in Fastest Skater (Cone Weave, racing the fastest star's run, skated by a bot at their pace) and Sharpshooter (Sniper, against their scores from their shooting); each event you win pays 75 coins, the runs don't use a training session, and you can try again or skip to the game. `tools/test_allstar.mjs` checks the vote, Skills Night and plays All-Star games.
- **Winter Classic:** once a season, after league round 3, the Foxes play an outdoor showcase on Pine Pond against the league leaders (or the runners-up if that's you). It doesn't count in the standings. Kip Vance calls it, the snow comes down harder, it has its own anthem, and a win pays a 320-coin purse, sets off fireworks, unlocks an achievement and goes in the trophy case. The schedule shows it between rounds 3 and 4. Pine Pond is dressed for it with a banner between two poles, string lights along the snowbanks, fire barrels in the corners and fans in toques and blankets (Batch W).
- **Draft Day:** once a season is over and the awards are handed out, Kip opens the draft: three prospects, one per position, with two to five stars of potential, a scout's line and their stats against your starter. Pick one and they join the roster as a rookie in your colours (the newcomer art), a couple of levels below your line-up; the other two go to rival clubs. The more stars, the faster a rookie earns EXP (up to 60% faster) and the further each stat can be raised. Starting a new season with the pick still open asks first. `tools/test_draft.mjs` checks the draft, rookies and career numbers.
- **Career stats:** Trophies › Career stats: the club's lifetime numbers (seasons, matches, wins, goals, cups, awards, All-Star Games, best daily streak), every skater's games, wins, goals, assists, points, shots, hits and steals (column leaders in gold), and Halla's games, saves, save percentage and shutouts. Tap a skater for their seasons and awards. Every full match counts (not drills or local versus); a save from before careers starts from the current season's league numbers.
- **Game plans:** before each league match pick Balanced, Forecheck, Trap or Run-and-gun. They change how both teams' AI plays, and Forecheck beats Run-and-gun, which beats Trap, which beats Forecheck. Rivals have a usual style (scouting report shown) and the Royals counter whatever you used on them last time. Pause › Game plan changes it mid-match (say, Run-and-gun when chasing a goal late), with a reminder of what they're playing and what beats it. The AI's bench adjusts too: two goals down late, it goes to Run-and-gun (once a match; the ticker says so).
- **Locker-room moments:** short scenes between league matches (tough losses, hat tricks, win streaks, playoff nerves, trash talk, scouting, Bram's stew and more). Each choice gives chemistry, EXP, coins or a buff for the next match.
- **Training rink:** six mini-games with bronze, silver and gold medals: Cone Weave (skating time trial), Sniper (hit targets off feeds), Keep-Away (pass chains against chasers), Breakaway (5 tries on a goalie) and Faceoffs (ten draws with the linesman dropping the puck, against a centre who reacts quicker every time, from half a second down to 0.18; offline only, no board) and Tip-Ins (ten point shots at the net: get your stick in the lane and press SHOOT as it comes by; goals off a tip count; offline only). They give EXP to the skater you bring, with 2 rewarded sessions between matches and unlimited practice. **Your best pace:** Sniper and Keep-Away keep your best run's points over time, and the HUD says how you stand against it as you go. **Ghost runs:** every Cone Weave and Breakaway run is recorded, and their cards pick a ghost to race: your own best, this week's best from the online board, or the best on one of your friends boards. In Cone Weave the ghost skates beside you, see-through and frosted with its name over its head, each gate shows how far ahead or behind you are, and the result says by how much you beat it or lost. In Breakaway each of its five attempts plays alongside yours (its skating, its puck flying at the net, then GOAL or SAVED), with its record in the HUD. **Challenge a friend:** after a run, share a link to it; the friend races your ghost straight from the link, and can send their run back. `tools/test_ghost.mjs` records a bot run, packs and unpacks it and races it.
- **Languages:** English and Icelandic (Íslenska), picked in Settings › Language. Browsers that list Icelandic before English start in it. All 1182 strings are translated: menus, dialogue, commentary, the HUD, drills, awards and locker-room scenes. People, teams, arenas and the club's own name stay as they are. Hockey terms follow `src/lang/GLOSSARY.md`. The translation was machine-made and checked in the game, so a native speaker's pass would still help.
- **Cloud save:** your save backs up automatically from the locker room under a random backup code (Settings › Cloud save). Enter the code, or open its link, on another device to carry on there. The server only stores a hash of the code, and nothing personal.
- **Online leaderboards:** Cone Weave, Sniper, Keep-Away, Breakaway, shootout wins and the best daily streak. Your best scores post automatically under your club name and a random tag (no accounts, nothing personal). The four drills also have weekly boards that start fresh every Monday at 00:00 UTC (the screen counts down to it, and a score set offline still counts for the week it was played). Your weekly and all-time ranks show after each drill, and the boards are under the cup in Training and Trophies, with gold, silver and bronze shields for the top three. **Friends boards:** make a board and share its six-character code (or an invite link) to get the same boards with just you and your friends, this week and all time; you can be on up to three, and joining copies your bests in. **Weekly Cup:** each friends board runs a cup every week over the four drill boards (5, 3 and 2 points for the top three on each, 1 for taking part); its table shows each player's place on every drill, and last week's top three stand on the podium. When a week ends, a top-three finish (on a board where at least two played) gets a toast and a place on the Weekly Cups shelf in Trophies. Scores made offline wait in a queue. Settings can turn it off, and a copy served from `localhost` stays off the live server unless the URL has `?online=1` (or `?lb=<url>` for a test server, like `node tools/leaderboard_server.mjs`). The server is one small AWS Lambda function and a DynamoDB table in eu-west-1, live since 8 October 2026 (`server/`).
- **Shootout:** five penalty shots each way against any rival. You shoot, then you play goalie, then sudden death.
- **Rivalries:** head-to-head records per rival. Captains bring up past scores, streaks and who lit them up, and the bracket shows the record.
- **Challenges:** exhibition modifiers (One-timers only, Giant goalies, Ice age, Lightning round, Heavy hitters, Next goal wins) with coin multipliers.
- **Local versus:** two players on one keyboard or with gamepads, plus gamepad rumble on hits, goals, combos and ultimates.
- **Accessibility and comfort (Settings):** aim assist (off/normal/strong), auto-sprint, relaxed game speed, screen shake strength, flashes off, reduced effects, colorblind-friendly team markers (blue triangles vs orange diamonds), large text, bigger touch buttons and a left-handed touch layout.
- **Photo:** Pause › Photo saves a picture of the ice as it stands (the share sheet on a phone).
- **Goal clips:** every instant replay is recorded as a short video with game sound and a caption. The results screen lists the match's highlights with Share (phones) and Save.
- **Achievements:** 55 trophies (hat tricks, comebacks, every combo and power puck, empty-netters, shorthanded goals, the cup, a perfect season, gold in every drill and more), each paying coins, shown in the Trophies tab.
- **Broadcast:** instant goal replays (skippable, toggle in Settings), play-by-play commentary ticker, ultimate cut-ins (a player from parts or a rookie gets their element's backdrop with their portrait), crowd chants that speed up the cheered team's ultimates, a team logo at centre ice.
- **Recruitment:** beat a rival and their three skaters take your call (Team › Scouting). Signings cost coins, join a level below your line-up's average with points to spend and the perks they already had, and wear your club colours. A centre, a winger and a defender dress for each match; every position plays its kit (centres Nix's frost kit, wingers Volta's thunder kit, defenders Bram's stone kit), so a signing brings different stats and style, not new powers. Chemistry is between people, so a new signing has to build it before combos fire. The rival fills the slot with a newcomer and brings it up before your next game. Benched skaters can still train.
- **Rivals with their own cast:** each of the five rivals has its own three skaters and goalie (on-ice sprites, portraits, cut-in banners), drawn in coral/violet and recoloured into the team's colours at runtime, plus its own crest. Captains change expression through the pre- and post-match talk, and so do Nix, Volta, Bram and Halla.
- **Arenas:** every rival hosts you in its own building: the Ember Comets in the Ember Dome (with a volcanic scoreboard), the Aurora Royals in the Aurora Palace, the Pinewood Lynx on Pine Pond (outdoors, no lamps), the Gilded Rams in the Golden Hall (braziers and gold banners) and the Obsidian Ravens in the Dark Aerie (violet lanterns and perched ravens). Each has the host crest at centre ice, a crowd mostly in the host's colours, its own scoreboard (volcanic, wooden, stone and gold, black stone), and the host's mascot dancing on the near stairs: a lynx, a fireball, a ram, a raven and a crowned polar bear, who cheer when their team scores at home. Quick play lets you pick the arena.
- **Arena rules:** each building plays differently. Ember Dome: meltwater pools drift across the warm ice and bog down skaters and the puck. Aurora Palace: aurora lanes push skaters and the puck along their arrows and shift every 14 seconds, with the next lanes flickering in first. Pine Pond: big hits, slapshots, one-timers and shockwaves crack the pond, and the cracks spread as the game goes on. Golden Hall: rumble strips run along the boards, and a puck carried fast across them now and then hops off the stick in a puff of ice dust. Dark Aerie: two ravens circle overhead, the puck nearly vanishes in their shadows, and goalies pick up shots from a shadow late. The Observatory (Glacier Owls): a pool of moonlight sweeps across the ice, and a shot from inside it glares in the goalie's eyes. The Longhouse (Thunder Moose): stretches of the wooden boards are loose and send the puck off at odd angles (`tools/test_rules.mjs`). The Frostline rink keeps the stage's twist (speed lanes, cracked ice). The pools, splashes, cracks and lanes are Batch I sprites: the pools ripple, cracks grow through four stages, and the aurora tiles scroll the way the lane pushes. The AI skirts slush and cracks and keeps the puck off the rumble strips; quick play can switch the rules off.
- **Crowd:** sprite fans fill the far stands and sit and cheer with the action; fans on the near benches are seen from behind (Batch N sprites) and throw their arms up on goals, and each bench has a flag waver. After a goal, the scoring side's fans run down to the far glass behind that net and bang on it, and camera flashes pop in the stands (not with flashes turned off).
- **Cut-ins:** ultimates and combos slide in the shooter's banner art; a goalie who stops an ultimate or combo gets a "DENIED!" banner.
- **Signature celebrations:** Nix plants an ice spike, Volta strikes a lightning pose, Bram hoists his stick, and each rival captain has their own (the Lynx howl, the Comets' fire burst, the Rams' headbutt, the Ravens' wing spread, the Royals' crown tip). The rival wingers and defenders celebrate too (Batch D): a knee slide, a comet spin, a hoof stomp, a cape glide, a sweeping bow and more. Rival skaters have side-on strides, hockey stops and glides like ours.
- **Title screen and finale:** the painted Puckbound logo, and an ice resurfacer that laps the empty rink (leaving a wet sheen) before each demo match faces off. Fireworks go up when you win the cup.
- **Menus:** every panel, button, tab, chip, shop card and dialogue box is drawn with the Batch U pixel-art kit (9-slice CSS `border-image`, so text stays HTML and wraps in both languages). With a controller, gold corner brackets pulse around the highlighted item, back buttons show ○ or B, L1/R1 (LB/RB) sit beside the tab bar, the highlighted shop card's Buy button shows ✕ or A, and the title screen, the controls help and the in-match key hints show the real PlayStation, Xbox or keyboard prompts. Arena rules have their own icons on the quick-play arena chips, the daily card and the rule announcement at faceoff (Batch O), and 14 achievements have icons of their own (Batch E). Batch X adds the Frostline Cup (with its glint) to the championship screen, medals to the training drills and drill results, and the daily star and streak flame. On phones the stick and buttons are pixel art too (Batch V), with a gold ring that pulses when Skill or Ultimate is ready, and glove and dive icons in goalie mode.
- **Your club:** rename the team (name, nickname, 3-letter code), pick its crest (the Snow Fox or six other designs) and its colours from eight presets or any trim and jersey colour (Team › Customise club, with a live preview). The name follows everywhere: hub, scoreboard, tables, results, awards, commentary, chants, rival trash talk and story dialogue. The colours go on everything that wears them: Nix, Volta, Bram, Halla, their portraits and cut-in banners, the crest, home fans, the arena banners, the Snow Fox and your signings. Our art's teal trim and cream jersey are recoloured inside our team's frames only, leaving skin, hair, outlines and effects alone.
- **Season awards:** every league season keeps a stat sheet for all 18 skaters and 6 goalies (real numbers from your games, believable ones from the simulated games, including newcomers in slots you signed away). When the season ends, Kip Vance hosts the Frostline Awards on a stage with velvet curtains and spotlights (Batch J), speaking from the podium, opening one envelope at a time and applauding each winner: League MVP, Golden Stick (goals), Playmaker (assists), Iron Wall (save %), Enforcer (hits) and Signing of the Year. Winners from your club earn coins and EXP and go into the award cabinet in Trophies; the League panel shows scoring leaders during the season and the winners after it.
- **Daily challenge:** one match a day, the same for everyone because it's seeded by the date: a rival, an arena with its rule, one or two challenge modifiers and a goal (win by 2, win in under 3 minutes, score a one-timer, win without a penalty, deke past defenders five times, take three faceoffs clean, and so on; a goal added later joins the draw from a date, so earlier days keep theirs). Beat it on consecutive days to build a streak; the reward grows from 120 to 300 coins. Start it from the Daily button in the hub.
- **Visible gear:** equipped gear shows on the ice. Each skate pair leaves its own trail and coloured skate marks (golden sparks for Bolt Runners, cyan frost for Hoarfrost Edges, dark gouges for Iron Boots, long blue lines for Long Track, carve spray for Pivot Pros). Special sticks glow where the puck is handled, crackle on the windup (sparks, frost, heat or a gravity swirl) and colour their shot trails. Protection shows when it works (stone shield flash, icy flash on blocks, golden sparkle on catches, visor glint). The shop and gear picker describe each look. Sticks, boots and blades are also recoloured on the sprites themselves in every pose, using the Batch M gear masks (`<sheet>_gearmask.png`: red stick, green boots, blue blades), for our skaters and signings alike, including the signings' side strides (Batch M2).
- **Locker room hub:** the hub opens in the locker room. Click the lockers (Team), the shop counter (Shop), the stick rack (Training), the crystal chest (Trophies) or the benches (League); stations show what needs attention (points to spend, scouts calling, sessions left, the next opponent). The dressed line-up and Halla stand on the floor. Coach Brekka stands by the training corner, Gearsmith Ottar at his counter and Kip Vance by the benches, idling, and talking while you point at their station; they also chime in on their panels, which keep tabs and a back-to-the-room button. A league board on an easel opens the League tab, and the trophy chest glows while there are trophies you haven't looked at, then stands open.
- **Animation:** 8-way skating, a 4-frame side stride with glide and hockey stop (with an ice spray), stagger and knockdown on big hits, and side-on goalie poses: shuffles, butterfly, glove and blocker saves, dives, covering the puck and getting up. A red goal light behind each net spins on goals.
- **Goalie life:** every goalie (Halla and the five rivals) has front, back, skating and puck-handling art, and true-profile side poses drawn facing both ways, so the glove is on the catching hand in either net. They wave at the opening faceoff, tap their pads before each draw, and celebrate goals for (or hang their head after a loss) facing the camera. After a goal against they turn, fish the puck out of the net and drop their head. They look back over their shoulder when the puck goes behind the goal line, wind up and sweep a pass when clearing a held puck, stop loose pucks with the stick, and poke-check carriers who cut in close. When a loose puck sits behind their net and they can beat everyone to it, they skate out around the net, stop it and play it, then skate back; if a forechecker gets there first they turn back, and now and then one catches them out. The AI dumps the puck in around the boards when it's pressured at the blue line with nothing on, then chases it. Halla stands in the locker room facing the camera.
- **Nets** are the v3 side-view sprites, back and front layers around the goal mouth, with the puck inside the mesh and a bulge on goals (code-drawn nets remain as a fallback). A goalie in the goal mouth stands inside the net, behind the near post and side mesh; out of the crease they draw in front of it.
- **Arena dressing:** near glass drawn over skaters along the bottom boards, a hanging scoreboard with the live score and clock, team banners in the home rink's corners (the Foxes plus the visitors), and the Snow Fox mascot dancing on the near stairs when the Foxes score.

The checker gathers every English string the game can show: the `t('…')` calls, the page's `data-i18n` text, and the story and data text in the modules. It then lists what the catalogue is missing or no longer uses, and flags translations with different `{placeholders}`, perks without exactly one colon, and straight double quotes. Add `--json missing.json` to write the missing strings out for translating. The merge tool adds a JSON file of English → translation pairs to `src/lang/is.js`. Wrap new display text in `t()` and re-run the checker before shipping. In the browser, `(await import('/src/i18n.js')).missingStrings()` lists any text looked up at runtime that has no translation.

Set `window.__debugRink = true` in the browser console to draw the collision boundary and nets.
